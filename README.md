Проект DIY-монитора качества воздуха на базе микроконтроллера ESP32. Устройство считывает показания с газоанализатора MQ-135, выводит их на OLED-экран и сигнализирует о статусе воздуха с помощью светодиодного светофора.

## ✨ Особенности проекта
*   **Дисплей OLED (128x64):** Отображает текущие показания датчика, текстовый статус воздуха и динамическую шкалу загрязнения.
*   **Светодиодный светофор:** 
    *   🟢 Зеленый: Воздух в норме.
    *   🟡 Желтый: Умеренное загрязнение.
    *   🔴 Красный: Плохое качество (с миганием для привлечения внимания).
*   **Умный синий светодиод (Heartbeat):** Плавно мигает раз в 2 секунды, показывая, что система работает. Если воздух становится критически грязным, переходит в режим "паники" (быстрое мигание).
*   **Стартовая анимация:** При включении устройство приветствует пользователя, тестирует все светодиоды и показывает обратный отсчет прогрева датчика (30 секунд).

## 🛠️ Необходимые компоненты
*   ESP32 (DevKit v1 или аналог)
*   Датчик качества воздуха MQ-135
*   OLED-дисплей SSD1306 (I2C, 128x64)
*   Светодиоды: Красный, Желтый, Зеленый, Синий
*   Резисторы на 220–330 Ом (для светодиодов)
*   Макетная плата и соединительные провода

## 🔌 Схема подключения (Pinout)
| Компонент | Пин на ESP32 | Примечание |
| :--- | :--- | :--- |
| **OLED SDA** | GPIO 21 | Стандартный I2C |
| **OLED SCL** | GPIO 22 | Стандартный I2C |
| **OLED VCC** | 3.3V | Питание |
| **MQ-135 AOUT** | GPIO 34 | Аналоговый вход (только чтение) |
| **MQ-135 VCC** | 3.3V | Питание (безопасно для АЦП) |
| **Red LED** | GPIO 25 | Через резистор на GND |
| **Yellow LED** | GPIO 26 | Через резистор на GND |
| **Green LED** | GPIO 27 | Через резистор на GND |
| **Blue LED** | GPIO 14 | Через резистор на GND |

*(Все пины GND компонентов соединяются в общую землю).*

## 🚀 Как запустить проект
1. Установите [Visual Studio Code](https://code.visualstudio.com/) и расширение [PlatformIO](https://platformio.org/).
2. Склонируйте этот репозиторий: `git clone https://github.com/ВАШ_НИК/air-quality-indicator.git`
3. Откройте папку с проектом в VS Code.
4. Подключите ESP32 к компьютеру.
5. Нажмите кнопку **Upload** (стрелочка вправо в нижней панели PlatformIO).
6. После прошивки устройство перезагрузится. **Дождитесь окончания 30-секундного прогрева датчика**, прежде чем смотреть на показания.

## ⚙️ Как это работает (Логика)
*   Код использует функцию `readSensor()`, которая делает 10 замеров подряд и вычисляет среднее арифметическое. Это защищает от "дрожания" показаний.
*   Пороги срабатывания (сырые значения АЦП от 0 до 4095):
    *   `< 1500` — GOOD (Хорошо)
    *   `1500 - 2500` — MODERATE (Средне)
    *   `> 2500` — BAD (Плохо)
    *   `> 3500` — CRITICAL (Критично, включается паника синего диода)
*   *Примечание:* Сейчас устройство выводит "сырые" значения (ADC). Для получения точных значений в PPM (миллионных долях) требуется калибровка в чистом воздухе и использование логарифмических формул из документации к MQ-135.
